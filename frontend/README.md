# SmartSport Frontend 🏆

This directory contains the React frontend codebase for the **SmartSport** portal. 

For the complete project overview, setup guides, and system architecture, please refer to the main repository README:
👉 **[Main Project README](../README.md)**

---

### Quick Start (Frontend Only)
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
   *Runs the app in the development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.*
