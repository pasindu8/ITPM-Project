# ITPM Project - Sports & Academic Management System

This is a comprehensive web application built using the MERN stack (MongoDB, Express.js, React, Node.js) developed as part of the Information Technology Project Management (ITPM) module. It features modules for Lineup Optimization, QR-based Attendance, Recovery Plans, Training Drill Libraries, and Schedule/Conflict management.

---

## 🚀 Features

- **Lineup Optimizer**: Smart tool to optimize team lineups and strategies.
- **QR Attendance**: Seamless attendance tracking using QR code generation and live feed scanning.
- **Recovery Plans**: Structured rehabilitation and training recovery schedules.
- **Training Drill Library**: A comprehensive repository for managing and filtering training drills.
- **Schedule & Conflict Management**: Efficient session scheduling with automated conflict detection.
- **User Authentication**: Secure forgot password, recovery, and login mechanisms.

---

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, Axios, ESLint
**Backend:** Node.js, Express.js, MongoDB (Mongoose)
